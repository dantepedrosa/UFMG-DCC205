# O que eu posso fazer? / What Can I Do?

Este documento descreve as capacidades e funcionalidades que posso oferecer ao trabalhar com este repositório de Estruturas de Dados (DCC205) da UFMG.

## Visão Geral

Sou um assistente de programação avançado com habilidades em várias linguagens de programação, especialmente C e C++. Posso ajudá-lo com diversos aspectos do desenvolvimento e manutenção deste repositório educacional.

## Capacidades Técnicas

### 1. **Análise e Compreensão de Código**
- Analisar código C/C++ existente
- Explicar algoritmos e estruturas de dados
- Identificar padrões de design e boas práticas
- Revisar código e sugerir melhorias

### 2. **Desenvolvimento e Modificação de Código**
- Implementar novas estruturas de dados
- Corrigir bugs e erros de compilação
- Refatorar código para melhor legibilidade
- Otimizar algoritmos existentes
- Adicionar novos recursos e funcionalidades

### 3. **Depuração e Testes**
- Identificar e corrigir erros de lógica
- Analisar problemas de memória (memory leaks, buffer overflows)
- Criar casos de teste
- Executar e analisar resultados de testes
- Depurar código usando ferramentas como GDB

### 4. **Documentação**
- Criar e atualizar documentação
- Escrever comentários claros no código
- Gerar READMEs informativos
- Documentar APIs e interfaces

### 5. **Build e Compilação**
- Trabalhar com Makefiles
- Resolver problemas de compilação
- Gerenciar dependências
- Configurar ambientes de build

## Exemplos de Tarefas que Posso Realizar

### Para Estudantes
1. Explicar como funciona uma estrutura de dados específica
2. Ajudar a depurar exercícios práticos (ap1-ap7)
3. Revisar soluções de trabalhos práticos (tp1-tp3)
4. Sugerir otimizações de código
5. Explicar complexidade de algoritmos

### Para Professores/Mantenedores
1. Adicionar novos exercícios práticos
2. Criar testes automatizados
3. Melhorar documentação existente
4. Refatorar código legado
5. Adicionar novas estruturas de dados à biblioteca xbib

### Tarefas Gerais
1. **Análise de Código**: "Analise o código de ordenação no tp1 e sugira melhorias"
2. **Correção de Bugs**: "Há um bug na implementação de pilha encadeada, pode corrigir?"
3. **Implementação**: "Implemente uma árvore AVL na biblioteca xbib"
4. **Documentação**: "Crie um README para o ap3"
5. **Otimização**: "Otimize o algoritmo de busca no grafo"
6. **Refatoração**: "Refatore o código de matriz para usar templates C++"

## Como Trabalho

1. **Análise**: Primeiro, analiso o código e estrutura existente
2. **Planejamento**: Crio um plano com mudanças mínimas necessárias
3. **Implementação**: Faço alterações cirúrgicas e precisas
4. **Verificação**: Testo e valido as mudanças
5. **Documentação**: Atualizo documentação relevante

## Limitações

- Não posso executar programas que requerem interface gráfica
- Não posso acessar recursos externos se não estiverem disponíveis
- Foco em mudanças mínimas e precisas para manter a integridade do código
- Respeito a estrutura e estilo existentes do projeto

## Como Me Usar

Para obter ajuda, seja específico sobre o que você precisa:

**Bons exemplos:**
- "Explique como funciona a implementação de HeapBinario.cpp"
- "Adicione testes para a classe ListaEncadeada"
- "Corrija o vazamento de memória no ap4"
- "Documente as funções públicas da classe Matriz"

**Evite:**
- Perguntas muito vagas: "Faça tudo"
- Solicitações sem contexto: "Corrija isso" (sem especificar o quê)

## Começando

1. Me informe sobre o que você precisa
2. Fornecerei um plano de ação
3. Implementarei as mudanças necessárias
4. Validarei e testarei o resultado
5. Documentarei as alterações

---

**Dica**: Quanto mais específico você for sobre suas necessidades, melhor eu posso ajudar!
